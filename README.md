# CLI WEATHER APP

Weather app built using python module "Requests"

## Installation and Procedures:
1. python -m venv .env
2. .env\scripts\activate.bat
3. pip install requests
4. pip show requests

### Installation from requirements.txt:
- pip install -r requirements.txt

## Working:
1. import requests
2. import json

### Running the project:
- open cmd
- python main.py
- enter city name
- check the weather_records/**records.txt** to see results.

## DESCRIPTIONS
Creating weather data that fetch data from a web server 

the webserver been used is **OpenWeather**
[https://openweathermap.org/](https://openweathermap.org/)

get your own api_key and start previewing weather data across the world
